### Что такое RE:I

**RE:I** — минималистичный VPN-клиент.

Идея проекта — убрать из пользовательского интерфейса лишнюю настройку VPN. Пользователь получает персональный код подключения вида:

```text
re:i//device_name#connect
```

После активации приложение самостоятельно получает доступный профиль, а пользователь может подключаться и переключаться между доступными серверами.

### Основные возможности

- подключение через персональный код;
- отдельный VPN-профиль для каждого устройства;
- переключение между доступными серверами;
- автоматическое восстановление VPN-соединения.

> RE:I находится в разработке. Состав функций и формат распространения могут изменяться.

### What is RE:I

**RE:I** is a minimal VPN client.

The project is designed to remove unnecessary VPN configuration from the user experience. Each device receives a personal connection code such as:

```text
re:i//device_name#connect
```

After activation, the application loads the assigned VPN profile automatically and allows the user to connect or switch between available servers.

### Main features

- personal connection codes;
- separate VPN profile for every device;
- switching between available servers;
- selective routing for services that should bypass the VPN;
- automatic VPN connection recovery.

> RE:I is currently under development. Features and distribution formats may change.
